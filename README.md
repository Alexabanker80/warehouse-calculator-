# Company Workspace System

Company: шиномонтаж БАШМАК

This repo is a structured, searchable company knowledge base. It is designed
to keep work organized by domain, standardize documentation, and make it easy
for humans and agents to collaborate.

## Quick start

1. Capture raw inputs in `/company/00-inbox`.
2. Clarify and move items into the correct domain folder.
3. Use templates from `/company/_templates`.
4. Keep cross-functional initiatives in `/company/20-projects`.
5. Follow naming and linking rules in `/company/CONVENTIONS.md`.

## Key docs

- `/company/README.md` for structure and workflow.
- `/company/CONVENTIONS.md` for naming and formatting rules.
- `/company/_agents/README.md` for agent responsibilities and outputs.
