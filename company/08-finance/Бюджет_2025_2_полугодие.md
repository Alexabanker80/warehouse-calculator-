## Summary

Файл содержит сводный БДР сети "Башмак" на II полугодие 2025 года,
а также расчетные листы по точкам. В файле есть листы:

- `Бюджет` - сводный БДР сети с план/факт по месяцам (Июнь, Июль, Август,
  Сентябрь, Октябрь-Ноябрь). Включает:
  - Клиенты, ПД, средний чек
  - Доходы по видам услуг и продаж
  - Расходы по статьям
  - Валовая прибыль и разбивка по объектам
  - Управленческие расходы
  - Чистая прибыль
  - Рабочие распределения и расчет безубыточности
- `Исх.данные` - исходные данные для расчета (в т.ч. ЗП прочая, питание,
  помесячные значения июнь-ноябрь).
- `ЗП` - расчет зарплат и коэффициентов.
- `Стат` - статистика по сезонам (весна/осень), выручка, клиенты, средний чек.
- `Клиент` - исторические данные по объектам.
- Листы по точкам: `Клин`, `Солн`, `Зелек`, `Химки`, `Пушк`, `Щелк`, `Андр`,
  `Дмитр`, `Пуш2`, `Щелк2`, `Клин2`, `Изумруд`, `Королев`,
  `Усть(без НДС)`, `ГрузДмитр`.
- `ИТОГО` - агрегаты по точкам (выручка, клиенты, ср. чек и др.).

Примечание: файл защищен паролем. Пароль хранится отдельно и не
фиксируется в репозитории.
