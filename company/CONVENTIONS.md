# Conventions

These rules keep files readable, searchable, and consistent.

## File naming

- Use kebab-case and ASCII only.
- Prefer `YYYY-MM-DD-topic.md` for dated docs.
- Use `topic.md` for living documents.
- Avoid spaces and special characters.

## Document header

Add a short header to new docs:

Title: <short name>
Owner: <name or team>
Date: YYYY-MM-DD
Status: draft | active | blocked | done
Related: <links>

## Linking

- Use relative links between docs.
- Link source material from `98-reference/`.

## Placement rules

- One home per document. Link elsewhere instead of duplicating.
- Cross-functional work belongs in `20-projects/` with links back to domains.
- Closed work goes to `99-archive/` but keep links intact.
