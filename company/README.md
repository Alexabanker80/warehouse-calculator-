# Company Knowledge Base

This folder is the single source of truth for company work. It is structured
by domain, with shared templates and conventions so content stays consistent
and easy to read everywhere.

## Workflow

1. Capture anything new in `00-inbox/`.
2. Triage weekly: move to a domain folder or `20-projects/`.
3. Use templates from `_templates/` for new docs.
4. Link related docs with relative links.
5. Archive closed work in `99-archive/`.

## Directory map

- `00-inbox/` - raw inputs, ideas, and notes
- `01-foundation/` - vision, strategy, OKRs, policies
- `02-operations/` - processes, SOPs, internal ops
- `03-product/` - product discovery, roadmap, PRDs
- `04-engineering/` - architecture, ADRs, tech notes
- `05-sales/` - pipeline, playbooks, pricing
- `06-marketing/` - campaigns, positioning, content
- `07-customer-success/` - onboarding, support playbooks
- `08-finance/` - budgets, forecasts, reporting
- `09-legal/` - contracts, compliance, policies
- `10-people/` - hiring, performance, culture
- `11-data-analytics/` - metrics, dashboards, analysis
- `12-partners/` - partnerships, alliances
- `20-projects/` - cross-functional initiatives
- `98-reference/` - vendor docs, external references
- `99-archive/` - closed or deprecated material
